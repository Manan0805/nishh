# Nishhu's Birthday Website ✨

A handcrafted, interactive, mobile-first birthday experience created by **Mann** for **Nishhu** (7th October 2026).

---

## 🌸 Features & Highlights

1. **Opening Reveal**
   - Elegant staggered typography: *"Hiii Nishuu 👀"*, playful teasing, and the *"come on, birthday girl →"* button.
   - Smooth auto-scroll transition into the story.

2. **7 Things I Like About You**
   - 7 interactive cards featuring Mann's exact reflections:
     - `01. YOUR EYES`
     - `02. YOUR SLEEPY FACE`
     - `03. YOUR ATTITUDE`
     - `04. YOUR VOICE`
     - `05. YOUR RANDOM RANTS`
     - `06. YOUR TRUST`
     - `07. YOU` *(Highlighted with a special design & border)*
   - Tap-to-expand / smooth reveal with active progress tracker.

3. **03.10.2026 Memory Journal**
   - Scrapbook / Polaroid styling with washi tape and paper texture.
   - The cab ride memory narrative where Nishhu fell asleep on Mann's shoulder.
   - Built-in atmospheric night cab-window illustration with glowing bokeh streetlights.
   - **Custom Photo Slot**: Mann can tap *"Mann's photo slot"* directly on the screen to preview any photo, or add a permanent photo in code.

4. **Something I Want You to Remember**
   - Calming, grounding, warm letter of reassurance honoring her feelings without pressure or guilt.

5. **It's The Little Things**
   - Interactive badge vignettes for:
     - *Random conversations*
     - *Your stupid jokes*
     - *Our FaceTime calls*
     - *Holding hands*
     - *Hugs*
     - *Falling asleep on my shoulder*
     - *Playing with your hair*
   - Tap each moment to uncover sweet handwritten-style notes.

6. **Before You Go...**
   - Heartfelt reflection on how a random Bumble match turned into something genuinely valued.

7. **Happy Birthday Finale & Blooming Surprise**
   - Full-screen centerpiece letter signed *"Yours lovingly, Mann"*.
   - Large *"one last thing →"* button revealing the playful post-credits surprise:
     - *"Waitttt. You thought I was finally done? 😂 ... And smile a little, okay? — Mann 🫶"*
     - Animated SVG blooming flower with soft drifting petal shower.

---

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Tailwind CSS** (Warm ivory `#FAF7F2`, soft blush `#F4DCD6`, sage `#9BAF96`, charcoal `#2C2520`)
- **Framer Motion** (Spring animations, card reveals, blooming SVG)
- **Lucide React** (Minimal, clean iconography)
- **Canvas Confetti** (Gentle petal burst)

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser (or use Safari on iPhone via local Wi-Fi IP).

---

## 🌐 1-Click Deployment (Vercel / Netlify)

### To Vercel:
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) → **Add New Project**.
3. Import your GitHub repository.
4. Click **Deploy** (Vercel automatically detects Vite).

### To Netlify:
1. Drag and drop the `dist` folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
2. Your website is live immediately!
